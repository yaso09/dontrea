TERMINAL — SETUP

            
KURULUM / GEREKSİNİMLER
Önce çalışma
ortamını hazırlayın.
Dontrea, Node.js 18 veya üzeriyle çalışır. Projeyi klonlayıp bağımlılıkları kurun; `npm link` komutuyla `dontrea` komutunu terminalden erişilebilir yapın. WebAssembly derlemesi için Javy isteğe bağlıdır.

          

          

            
TERMINAL — SINGLE FILE

            
TEK DOSYA
Kaynağı seçin,
çıktıyı belirleyin.
`-i` giriş HTML’ini, `-o` korunan çıktı yolunu belirtir. `-p` payload’ı kaç gizli parçaya böleceğini ayarlar. Komut satırı parametreleriyle tek sayfayı hemen derleyebilirsiniz.

          

          

            
TERMINAL — PROJECT BUILD

            
PROJE YAPILANDIRMASI
Birden fazla sayfayı
tek seferde derleyin.
`dontrea config add`, dosya başına giriş, çıktı ve koruma ayarlarını `dontrea.json` içine kaydeder. Yapılandırma yoksa oluşturur. Sonra `dontrea build` listedeki bütün HTML dosyalarını sırayla işler.

          

          

            
TERMINAL — CODE SHIELD

            
JAVASCRIPT KORUMASI
Koruma katmanlarını
ihtiyacınıza göre seçin.
Kontrol akışı düzleştirme, ölü kod enjeksiyonu, self-defending ve geliştirici aracı korumasını açın. `--domain-lock` ile kodun çalışacağı alan adlarını sınırlayın; parçalama sayısını ve eşikleri ayarlayın.

          

          

            
TERMINAL — RUNTIME

            
WASM / SAFE-FALLBACK
Motor çalışma
kodunuza uyum sağlar.
Javy kullanılabiliyorsa Dontrea JavaScript’i WebAssembly’e derleyebilir. Canvas ve ses gibi tarayıcı API’lerini saptadığında otomatik olarak Safe-Fallback JS modunu seçer. İsterseniz `--force-wasm` ile derlemeyi zorlayın ya da `--no-wasm` ile Wasm’ı kapatın.

          

          

            
TERMINAL — OUTPUT

            
PAKETLEME / ÇIKTI
Tek HTML dosyası,
dağıtıma hazır.
Dontrea kodu HTML içine parçalı olarak yerleştirir ve yapıyı sıkıştırır. `--dynamic` Javy’nin dinamik sağlayıcısını seçer; `--wasm-binary` önceden derlenmiş bir Wasm dosyasını gömer. Sonuç, belirlediğiniz konuma yazılan tek HTML çıktısıdır.
